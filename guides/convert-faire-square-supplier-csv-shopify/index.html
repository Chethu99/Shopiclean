If you run a retail boutique, curate wholesale goods, or migrate from brick-and-mortar POS systems, your inventory lives in external spreadsheets:

  • Wholesale order sheets exported from Faire or Abound.
  • Inventory reports downloaded from Square POS or Clover.
  • Custom warehouse spreadsheets provided by overseas dropshipping distributors.

When you attempt to drop these files directly into Shopify Admin > Products > Import, Shopify rejects the file with errors such as:

Missing required header: Title. Found unrecognized columns: Item Name, Price Point, Token.

Shopify requires a strict 50-column structure with exact capitalization and specific data types. Here is the manual mapping reference and how to automate the transformation.

The Essential Column Translation Table

To make any external wholesale spreadsheet work with Shopify, you must map their custom headers to Shopify's primary specification:

Standard Supplier Header Required Shopify Header Transformation Rule
Product Name / Item Name Title Must be non-empty on primary rows.
(Derived from Name) Handle Lowercase, hyphenated slug (no spaces).
Retail Price / Selling Price Variant Price Strip currency signs ($/€); numeric only.
Wholesale / MSRP Variant Compare At Price Optional; shows discounted strike-through.
Stock Qty / On Hand Variant Inventory Qty Integer format only.
Barcode / Item Code Variant SKU Unique alphanumeric code.

3 Sneaky Errors When Converting in Excel

  1. Currency Formatting Traps: Wholesalers format price cells as currency (e.g. $24.50). Excel keeps the dollar sign when exporting to raw CSV, causing Shopify to fail on numeric validation.
  2. Missing Inventory Tracker Policy: If you supply quantities in Variant Inventory Qty without specifying Variant Inventory Tracker = shopify, Shopify will ignore your stock counts completely.
  3. Truncated Barcodes: Excel often treats 12-digit UPC or EAN barcodes as scientific numbers (e.g. 7.89E+11), permanently corrupting your product identifiers.

Frequently Asked Questions

Does this overwrite existing products in my store?

Only if you check the box inside Shopify Admin that says "Overwrite existing products that have the same handle". Otherwise, Shopify will create new products alongside your existing listings.

Can I import product tags and collections through this method?

Yes. The converter maps supplier category fields directly into Shopify's Type and comma-separated Tags columns so your automated collections categorize items immediately on upload.
