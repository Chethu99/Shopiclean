Why Does Shopify Report "Illegal Quoting"?

Shopify’s product import engine parses spreadsheets strictly using the standard RFC-4180 CSV specification. Under this standard, quotation marks (") are special control characters used to wrap fields that contain commas or line breaks (such as HTML product descriptions).

The error "Illegal quoting on line X" occurs when the parser encounters a double quote inside a cell that was not properly escaped. When this happens:

  • The parser assumes the field ended abruptly.
  • Commas inside your text description are suddenly treated as column dividers.
  • Every subsequent column shifts horizontally into the wrong field, breaking price, variant SKU, and inventory values.

The 3 Most Common Culprits

1. Dimension Symbols in Product Titles

Using raw double quotes for inches or feet in titles (e.g., Modern 12" Wall Clock) will immediately break standard CSV parsers unless wrapped properly.

2. Unescaped Quotes in HTML Descriptions

When exporting product descriptions containing HTML elements (like <a href="https://example.com">), software like Excel or Numbers often fails to escape the internal quotes when exporting to CSV format.

3. Quotation Marks Copied from Word or Google Docs

Pasting "smart quotes" or "curly quotes" (“ ”) can cause unexpected encoding conflicts when converted between UTF-8 and ISO spreadsheets.

How to Fix the Error Manually

According to RFC-4180, if a field contains a double-quote character, that quote must be escaped by prefixing it with another double quote (""), and the entire field must be enclosed in quotes.

// Incorrect (Fails with Illegal Quoting):

modern-wall-clock,Modern 12" Wall Clock,Decor,45.00

// Correct (RFC-4180 Compliant):

modern-wall-clock,"Modern 12"" Wall Clock",Decor,45.00
