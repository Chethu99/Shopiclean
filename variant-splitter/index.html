Frequently Asked Questions

How does Shopify know rows belong to the same item? ▼

Shopify groups variant rows based on identical, consecutive Handle values. This tool propagates the parent product's handle downward across subsequent option rows so Shopify groups them cleanly under one product dropdown.

Why split variants into separate parent product listings? ▼

Bundling excessive option combinations under one listing hides colorways from Google Shopping search results and exhausts image gallery real estate. Splitting items by color gives each option its own dedicated landing page, custom photography, and direct search traffic.
